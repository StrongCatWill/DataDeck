# Notification

A row in the Notifications screen, reached from the bell on Today.

- Unread rows are tinted `sleep-t` with a red dot; opening the screen marks them read.
- Each row opens the thing it is about: the pack, a loan, the wallet, the Levels sheet.
- Sources: pack ready, quest done, level up, loan started, first payout, sharing stopped, request refused, cash out.
- Never "last chance" or countdown messages about lending. "New studies" is off by default.
