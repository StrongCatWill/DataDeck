# TabBar

A floating, rounded dock with five tabs, each an icon and a word: Today, Deck, Bounties, Wallet, You.

- The current tab's icon sits in a `sleep-t` bubble that pops in.
- A `heart` dot on Deck means an unopened pack; on Bounties, a study that matches a card.
- 66pt tall, 10pt from the screen edges, plus the bottom safe-area inset. Hidden during first run.
