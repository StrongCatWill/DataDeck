# Quest

One daily goal: an icon badge, the goal, a progress bar and the XP it gives. Each row is a button that opens the screen where the quest is done.

- Three a day: steps, sleep, and opening the weekly pack.
- Done state (`dd-quest dd-done`): the row turns `steps-t` and the icon becomes a check.
- Rewards are XP only. No quest is about lending, and no quest pays USDC.
- Goals come from the player's own Daily goals, so the text reads "Walk 6,000 steps".
